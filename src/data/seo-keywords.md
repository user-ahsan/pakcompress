# SEO keyword clusters

## How the 2,000 to 3,000 queries are counted

5 sizes x 8 file types x 15 portals x 4 intents = 2,400 base combinations.
Add city and board variants, and the set grows past 3,000.
We do not build 3,000 thin pages. We build 60 real pages now.
The rest stay as data in src/data/presets.ts and are added only when a
cluster has real search demand and a real guide to match it.

## Clusters

### Sizes
20 KB, 50 KB, 100 KB, 200 KB, 500 KB

### File types
photo, signature, CNIC photo, PDF, JPG, PNG, image, document, scan

### Portals
FPSC, PPSC, SPSC, KPPSC, BPSC, NTS, NADRA, HEC, BISE Lahore, BISE Karachi,
UHS, NUST, LUMS, University of the Punjab, IBA Karachi

### Intents
compress, resize, reduce size, make passport photo, convert to PDF

### Example queries
- compress image to 20kb
- compress photo to 50kb for FPSC
- compress image to 100kb for job portal
- resize photo to 200x250 for NTS
- passport size photo 35x45 mm Pakistan
- compress PDF to 200kb
- CNIC photo size 20kb NADRA
- PPSC photo size in KB
- HEC photo size for attestation
- compress signature to 20kb

## Rules for new pages
- One page per real need, not per keyword trick.
- Each page must have a working tool, a clear target, and a short guide.
- Each portal page must say: Always check the official advertisement,
  requirements change.
- No page without a tool or a guide goes live.
