# Monetization — retired

PakCompress is free forever. There is no paywall, no checkout, no paid plan,
and no payment provider. Everything is free: single-file compress, batch up to
10 photos, ZIP download, passport photo and A4 print sheet, PDF to exact KB,
the cropper, and all 5 languages.

## If monetisation is ever added

The only option under consideration is advertising (for example Google
AdSense) once the site has real traffic — ads below the tool, never above it,
and never blocking a tool. No tool feature will ever be put behind a paywall.
